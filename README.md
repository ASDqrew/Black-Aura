# Alexander Cut — website

Static responsive website for a biowave hairstylist. It features Alexander's work and links to the current YCLIENTS pricing and booking flow.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Content updates

- Replace the YCLIENTS link if Alexander's booking address changes.
- The current booking flow uses YCLIENTS, followed by photos, prepayment, and receipt confirmation with the administrator.
